# How does the assistant help with a pull request?
Three buttons on a pull request (write the description, review, reply) open the assistant with the pull request in the draft. A person reads the draft and sends it. No run starts by itself.

Options:
1. Fill the draft of the assistant, a person sends it. (chosen)
2. Start a run at once with the pull request as the task.

## Answer
Fill the draft of the assistant, a person sends it.
