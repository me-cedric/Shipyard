# How does Shipyard treat a reply that is not a clear answer?
A reply can be a number out of range, a letter with no option, or text on a question that allows no free text. A wrong reading resumes the run with a wrong answer.

Options:
1. The run keeps waiting. The card shows the reply. The person confirms it or chooses an option. (recommended)
2. Post a comment that asks for a new reply. This needs the `tracker_comment` switch.
3. Read any other reply as free text.
