# Does the status-bar sync action also pull git?
The shell has one sync action. The earlier tool had pull in three places, and push as a second decision. The sync action of `add-sync` runs one tracker tick.

Options:
1. One tick, then fetch and fast-forward the working branch when the working copy is clean. Publish stays a separate click in Code / Branches. (recommended)
2. The sync action runs the tick only. Code / Branches has Pull and Publish.
3. The sync action pulls and publishes after the tick.

## Answer
One tick, then fetch and fast-forward the working branch when the working copy is clean. Publish stays a separate click in Code / Branches.
