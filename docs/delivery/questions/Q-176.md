# What is a release?
The design shows a release "MVP 1" on the ticket page, in Plan, in Costing and in Dashboards.

Options:
1. The version of the issue tracker: Jira fix version, GitHub and GitLab milestone, Azure DevOps iteration, Linear project.
2. An estimate sheet of Shipyard.
3. A new field that only Shipyard keeps.

## Answer
Option 1: a release is the version of the issue tracker, and it syncs with it. Azure DevOps uses the iteration and Linear uses the project: a lead default. (2026-11-20)
