# Must the name of a control contain its visible text?
The axe rule `label-content-name-mismatch` (WCAG 2.5.3, Label in Name) flags two controls. A Gantt bar shows the owner but has the name of the item. The notification bell shows the unread count but has the name "Notifications". Tests in `app.test.tsx` and `notifications.test.tsx` use the name "Notifications". `e2e/design-system.spec.ts` turns this one rule off until you decide.

Options:
1. Keep the names, and keep the rule off in the gallery e2e. (recommended)
2. Put the visible text in the name ("Notifications, 1 unread", "Login screens, AB") and update the tests.
