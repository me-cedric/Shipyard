# What does a ticket edit send to each tracker?
The ticket detail edits the title, the description, the labels (add and remove), the assignee, the status and the priority. Each write is one click and respects the read-only lock. A capability answer (`work_ticket_edit_caps`) hides a control that the tracker cannot honour. Priority has five values (highest to lowest). Jira sends the name, Azure DevOps and Linear send 1 to 4 (low and lowest share 4). GitHub and GitLab have no priority field and refuse before a request. Linear and Azure remove a label by its id or by the tag text. The description replaces the old one.

Options:
1. Five fixed priority values mapped by each adapter, controls hidden by a capability answer. (chosen)
2. Free text priority sent as typed.
