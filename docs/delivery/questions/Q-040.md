# Which diagram formats does Shipyard edit in the app?
Excalidraw, draw.io, Mermaid and BPMN files all need a view. An editor for each one is a large part of the work.

Options:
1. Edit Excalidraw and Mermaid in the app. Show draw.io and BPMN read-only, with an action to open the file in another app. (recommended)
2. Edit all four formats in the app.
3. Show all four read-only.
