# Where do the non-secret settings of a connection live?
A connection has a host address, a kind and options. Machines of one team use the same tracker but may use other addresses. The constitution keeps machine state out of the repository.

Options:
1. In the app data folder. `.shipyard/project.yaml` names the connection id only. (recommended)
2. In `.shipyard/project.yaml` with the host address. Each machine adds its secret.
3. In the app data folder only. The project file names nothing.
