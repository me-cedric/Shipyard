# Where do the pinned tiles live?
REQ-024 says that the pins are a per-person setting. The app already keeps a per-person preferences file in the app data folder. A pin names a dashboard and a tile id.

Options:
1. A `pins` list in the preferences file of the person. (recommended)
2. One pins file for each project in the app data folder.
3. A pins block inside the dashboard file. This shares the pins with the team and breaks REQ-024.
