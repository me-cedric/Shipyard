# What are the default budgets?
A run needs a budget (constitution 5.5). The workflow example sets 5 USD for a run. No source gives a default for a day or for a member.

Options:
1. The workflow limit sets the run budget (5 USD in `feature`). No default per day or per member until an admin sets one. (recommended)
2. Run 5 USD, day 25 USD, member 10 USD by default.
3. No default at all. Each admin sets every budget.
