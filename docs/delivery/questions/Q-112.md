# Do the push-target check and the docs-chain gate block?
Both warn above the Publish and Commit actions. The push target reads the repository on the forge connection of the host (can push, default branch). The chain is fixed: a change in specs asks for designs, models, api, data and test plans; a change in api asks for test plans. The gate never blocks.

Options:
1. Warn and never block. (chosen)
2. Block the action until a person confirms.
