# Which runner writes the digest of a pull request body?
Delivery now calls the digest when it opens a pull request (Q-079, option 1). The digest costs two agent turns. The factory runner of the project runs them. The Analyze view of Code uses the assistant default runner of the project instead.

Options:
1. The factory runner writes the digest. One runner for all work of a run. (recommended)
2. The assistant default runner writes it, as in the Analyze view.
3. A separate setting for the digest runner.

## Answer
The factory runner writes the digest. One runner for all work of a run.
