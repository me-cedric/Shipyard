# Can the creator make a public repository?
The existing `create_repo` of the code host makes a private repository. A public repository exposes the brief and the code of a client at once.

Options:
1. Private only. A person makes the repository public on the code host. (recommended, built)
2. A Private / Public choice in the remote step.
