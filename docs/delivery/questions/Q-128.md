# Where does the screens toggle live?
The spaces and the tabs that a project hides live with the project profile in the app data folder (`profileTabs`, `hiddenTabs`), so each person picks their own screens. Settings never hides, a space keeps one tab at least, and a hidden tab sends a visit to the first tab that stays. An option writes the surfaces to a file in the repository, so the whole team gets the same screens.

Options:
1. Per machine, with the profile. (chosen)
2. In the repository, for the whole team.

## Answer
Per machine, with the profile.
