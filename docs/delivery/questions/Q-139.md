# Which theme wins: the project theme or an imported theme?
A project can set the theme for all its members (`projects` REQ-010). A person can also pick an imported theme in Settings / Me.

Options:
1. The project theme wins, as for each project override. The imported theme applies again in a project with no override (default until an answer).
2. The imported theme wins, and the project theme gives only the base.
