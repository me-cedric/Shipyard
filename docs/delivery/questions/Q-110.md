# How does a person get a forge token from `gh` or `glab`?
The app runs `gh auth token --hostname HOST` (or `glab config get token --host HOST`) after a click, saves the value in the keychain and tests it. A token that the forge refuses leaves no connection. The git credential helper and the device login of Legacy are not part of this change.

Options:
1. Read the token from the tool after a click, test it before it stays. (chosen)
2. Add the git credential helper and the device login.
