# May Settings / Agents and rules change the pinned compass version?
ADR 0010 pins compass to a tag in a submodule. The view shows the pin and the sync state. Moving the pin is a change to the repository that the team shares.

Options:
1. Show only. A person moves the pin with git, and the view shows the new state. (recommended)
2. Offer a Move action that sets the submodule to a chosen tag and runs `ac sync`.
3. Offer a Move action that only proposes the change as a branch.
