# Does the Azure DevOps pull request show a diff?
REQ-019 shows the files of a pull request with their diff. The Azure DevOps REST API sends the changed paths and no patch. The adapter returns the file list with no patch, so the view shows the path and the change type only.

Options:
1. Show paths only on Azure DevOps, and link to the forge for the diff. (recommended)
2. Fetch the head and compute the diff with git in the working copy when the branch is local.
3. Call the Azure DevOps diff endpoint for each file and fetch the two file versions.
