# How does the claim stamp relate to the automation write switches?
A claim stamp on a ticket is a tracker write. The factory switches `tracker_transition` and `tracker_comment` are off by default (Q-002). A claim that waits for a click cannot stop a second machine in time.

Options:
1. The claim stamp is not one of the four switches. Turning on the pickup rules allows it. (recommended)
2. The stamp follows `tracker_comment`. With it off, the claim stays local and two machines can collide.
3. Add a fifth switch `claim_stamp`, off by default. Pickup needs it on.
