# Does a connection read the credentials of git, gh and glab before the keychain?
A remote credential can resolve from git credential helpers, then gh, then glab, then its own keychain entry. The constitution says a secret lives in the OS keychain. Reading a helper adds convenience but a second secret source.

Options:
1. No. The Shipyard keychain entry is the only source. A person pastes a token once. (recommended)
2. Yes. Try the git credential helper first, then the keychain entry.
3. Yes, for git clone and push only. API calls use the keychain entry.

## Answer
No. The Shipyard keychain entry is the only source. A person pastes a token once.
