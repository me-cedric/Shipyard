# How does a person confirm the replacement of a file in the project import?
REQ-015 forbids a replacement without a person's confirmation. W9 builds no confirmation step. The import lists a file that exists as a conflict and leaves it unchanged. A person moves or deletes the Shipyard file and runs the import again.

Options:
1. Keep conflicts unchanged. No replacement path. (recommended)
2. Add a per-file confirm in the import view. The command takes the list of confirmed paths and replaces only those files.
3. Replace after one confirm for the whole import.

## Answer
Keep conflicts unchanged. No replacement path.
