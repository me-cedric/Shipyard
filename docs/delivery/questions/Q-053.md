# Three run engine defaults that the master plan does not set
The factory spec needs these defaults. MASTER-PLAN section 5 does not give them.

1. A run leaves `Paused` only when a person raises its budget and resumes it (REQ-005).
2. When the review rounds are spent and findings remain, the run moves to `Blocked` with the findings in the log (`add-delivery` REQ-004, cited by factory REQ-036).
3. The HTTP transport of the agent tools accepts only calls from this machine (REQ-037).

Options:
1. Keep the three defaults. (recommended)
2. Change one or more of them. Name the change in the answer.

## Answer
Keep the three defaults.
