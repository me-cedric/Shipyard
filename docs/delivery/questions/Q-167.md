# What is the default cap of fix rounds for a whole run?
A fix round is each return to `Working` to fix a finding, a red gate, a conflict, an empty branch or feedback. The defaults are 4 review rounds and 3 feedback rounds, so a run that uses both can reach 7 rounds before one fixer round.

Options:
1. 8 fix rounds: the 4 review rounds, the 3 feedback rounds and one fixer round. (recommended)
2. 6 fix rounds: a lower cost cap. A run that spends its review rounds then has few rounds for the feedback.
3. No run-wide cap: the review and feedback caps stop the loop.

## Answer
Option 1: 8 fix rounds: the 4 review rounds, the 3 feedback rounds and one fixer round. Recommended default, kept: the owner asked to build the no-stuck, no-loop flows with sensible defaults (2026-11-06). The owner can change it.
