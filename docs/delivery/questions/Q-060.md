# Which day rate applies to a task role when several members share the role?
A sheet task names a role. The team file holds a day rate for each member. Two members with one role can have two rates.

Options:
1. Use the mean rate of the members with that role. (recommended)
2. Use the highest rate of the members with that role.
3. Let the sheet task name one member, and use that rate.

## Answer
Use the mean rate of the members with that role.
