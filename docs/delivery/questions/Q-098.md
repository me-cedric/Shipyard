# Where do the changelog sections come from after an update?
The update check reads one release answer (`releaseUrl`). It takes the `body` of that release and keeps the sections `## <version>` above the last seen version (preference `seenVersion`) and up to the latest. A body with no version heading is one note. This works when each release body holds the changelog sections since the last release. The check does not read older releases and does not read `CHANGELOG.md` from the repository.

Options:
1. Keep it: the release body carries the sections. Make the release job copy them from `CHANGELOG.md`. (recommended)
2. Also read the list of releases and join their bodies. It costs one more request and a larger answer.
