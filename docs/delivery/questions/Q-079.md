# When does a run get its digest for the pull request?
REQ-032 gives the digest of a run's diff to delivery. `run_digest` in `crates/shipyard-app/src/code.rs` builds it with one agent ask. The delivery engine still sets `impacts: None` in the pull request body. A call at each pull request would cost one agent turn for each run.

Options:
1. Delivery calls `run_digest` once, when it opens the pull request, and skips it when the agent runner is not set. (recommended)
2. Delivery asks for the digest only when the person clicks Analyze on the run.
3. Do not add a digest to the pull request body in this version.
