# How does a deck export as one file that opens offline?
REQ-018 asks for one file with no network. No command writes a deck file, so Knowledge / Slides has present mode but no export yet.

Options:
1. Add a `slide_export_file` command in the Rust store. It writes one HTML file with reveal.js, the theme and the slides inline. It gets a Rust test. (recommended)
2. Build the HTML in the webview and write it with a generic file command.
3. Leave the export out of this version. Present mode stays the only output.
