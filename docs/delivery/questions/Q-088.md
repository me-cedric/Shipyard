# Is the terminal a tab or a panel on every view?
REQ-034 asks for a panel that opens from every view with a keyboard shortcut, and for Open terminal here on a folder. The tab list of the Code space names `terminal`, so the terminal is a tab now. Its shell lives while the tab is open and ends when the person leaves it (REQ-035).

Options:
1. Keep the tab in this stage. Build the panel, the shortcut and Open terminal here in the shell stage. (recommended)
2. Build the panel in the app shell now. The tab then opens the panel.
