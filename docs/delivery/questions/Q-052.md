# How does a person update an imported plugin?
A plugin has a version. A newer archive may change files that the person already edited. The review must show the change against the applied version.

Options:
1. Import the newer archive. The review shows a diff against the applied version and each item. (recommended)
2. Remove the old plugin first, then import the new one.
3. Refuse a second import of the same plugin id.
