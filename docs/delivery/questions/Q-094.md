# Is EditorFrame the Editor template?
REQ-006 lists five templates: Shell, Board, List and detail, Editor and Settings. `src/ui/templates/` holds four files. The Editor frame is the organism `EditorFrame` in `src/ui/organisms/editor-frame.tsx`. It frames the title, the ref chip, the save state and the one primary action of every Design and Specs artifact. `templates.test.tsx` tests it as the fifth template.

Options:
1. Keep `EditorFrame` where it is, and count it as the Editor template. (recommended)
2. Move it to `src/ui/templates/editor.tsx` and update the imports.

## Answer
Keep `EditorFrame` where it is, and count it as the Editor template.
