# Which contrast targets apply to the themes?
The high-contrast option needs a measurable target. Legacy has the option but no stated ratio.

Options:
1. WCAG AA (4.5:1 text) by default, AAA (7:1 text) in high contrast. (recommended)
2. WCAG AA in both.
3. WCAG AAA in both.
