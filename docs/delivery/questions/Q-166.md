# What does a run do when its step has spent its retries?
Today, spent retries move the run to `Failed`, a final state with no report. The new attempt breaker and the escalation give a person one more round instead.

Options:
1. Spent retries and a spent breaker escalate to `Blocked`. The engine sends no new run to `Failed`. `Failed` stays in the table for the runs of older logs. A person ends a blocked run with Cancel. (recommended)
2. Spent retries move the run to `Failed`, as today, and the run posts one stop report. A new run starts only when the ticket changes.

## Answer
Option 1: Spent retries and a spent breaker escalate to `Blocked`. The engine sends no new run to `Failed`. `Failed` stays in the table for the runs of older logs. A person ends a blocked run with Cancel. Recommended default, kept: the owner asked to build the no-stuck, no-loop flows with sensible defaults (2026-11-06). The owner can change it.
