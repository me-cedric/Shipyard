# Does Shipyard keep the tours and the per-project visible tabs?
The earlier tool shows a tour, a changelog and help bubbles on first run, and a project can hide tabs. The constitution forbids helper text and forbids a role to lose a view.

Options:
1. Drop both. First run shows the project picker and the role choice only. (recommended)
2. Keep a one-time tour with icons and nouns only. Drop hidden tabs.
3. Keep both and amend the constitution with an ADR.

## Answer
Drop both. First run shows the project picker and the role choice only.
