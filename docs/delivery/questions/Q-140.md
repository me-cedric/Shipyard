# Does the import refuse a theme with low contrast?
A theme file can set text colours that do not meet WCAG AA (4.5:1) on its surfaces. The built-in themes meet it.

Options:
1. Accept the theme. The preview shows it and the person decides (default until an answer).
2. Show the contrast of the text tokens in the preview, and accept the theme.
3. Refuse a theme whose text tokens are below 4.5:1 on surface 0.
