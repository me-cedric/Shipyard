# Which views open their first item by default?
A list beside a detail (the Design tabs, Knowledge / Handbook and Documents, Code / Changes, History and Pull requests) opens its first item and keeps the choice of each tab while the app runs. Specs / Changes, Capabilities and Test plans show cards that open one item in place of the list: they keep the open item of each tab but do not open one by default, because the cards are the overview. The Knowledge slides grid works the same way. Settings has no list beside a detail. An empty list shows a ghost layout and one primary action.

Options:
1. First item in a list beside a detail; the open item kept in a card view. (chosen)
2. First item everywhere, also in the card views, so the cards never show until Back.
