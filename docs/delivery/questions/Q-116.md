# How does Shipyard find the AI sessions of this computer and price them?
Shipyard lists the agent processes with ps and reads the transcripts of Claude Code and Codex. It prices tokens from a built-in list price per model, so a cost is an estimate, and a model with no price counts as 0. A day is the UTC date. An alternative runs ccusage for prices and also reads Copilot.

Options:
1. Own reader, list prices, Claude Code and Codex only. (chosen)
2. Run ccusage, and read Copilot.
