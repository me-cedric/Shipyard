# Which absent compass entries are a Health finding?
REQ-007 makes a stale or absent entry a finding. Most skills and packs are optional, so every entry that a person never chose would be absent. Health would list dozens of findings that are not defects.

Options:
1. A stale entry is a finding. An absent entry is a finding only for the contract. (recommended)
2. Every absent entry is a finding.
3. An absent entry is a finding only when `.agents/compass.json` lists it but the lock does not hold it.
