# Do the label catalogues stay in typed TS files?
T010 names `src/lib/i18n/ui.fr.json` and `src/lib/i18n/ui.en.json`. The project keeps labels in typed TS files, one per feature, in `src/lib/i18n/`. `fr` has the type `Messages`, so a missing key fails the type check. A test in `i18n.test.tsx` also checks the keys, the empty labels and the placeholders of both languages.

Options:
1. Keep the typed TS files. Do not add JSON files. (recommended)
2. Move all labels to `ui.en.json` and `ui.fr.json`, and generate the types from them.
3. Keep TS for features and add JSON for the shared `src/ui` labels only.

## Answer
Keep the typed TS files. Do not add JSON files.
