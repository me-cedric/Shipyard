# Does a project switch show the last view of the target project?
REQ-015 says the app shows the last view of a project on open. The code restores it when the app starts. A switch in the project switcher shows the role home of the target project. The mock IPC keeps no state across a page reload, so the e2e test cannot restart the app. The vitest test in `src/features/projects/projects.test.tsx` covers the restart.

Options:
1. Restore only at start. A switch shows the role home. (recommended)
2. Restore at start and at each switch.
3. Persist the mock state in the browser, so the e2e test can restart the app.

## Answer
Restore only at start. A switch shows the role home.
