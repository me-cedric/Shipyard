# Which form of address do German and Spanish use?
French uses "vous". Business software in German often uses "Sie". Software in Spanish often uses "tú".

Options:
1. German "Sie", Spanish "tú". The assistant prompts use the familiar form, as in French. (recommended, built)
2. German "du", Spanish "tú".
3. German "Sie", Spanish "usted".
