# Does an abort of a branch merge need a confirm?
Code / Branches merges a branch with one click and aborts a merge in progress with one click. The merge refuses while a tracked file has a change. An abort puts the working copy back to HEAD, so the resolutions that a person made during the merge are lost. No dialog asks first.

Options:
1. One click, as the git command does. (chosen)
2. Add a confirm that names the files that hold a resolution.
