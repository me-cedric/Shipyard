# Does Shipyard read the existing layout in place, or import it?
Shipyard now reads the existing layout in place. A folder with no project file gets a project file whose paths point at what exists (docs/drawings, .c4 files under docs/diagrams, docs/network/flows.json). The JSON files (flows, costing sheets, the planning team file) open and save in their own format. The import stays as an optional converter to Shipyard YAML. It copies no more artifact folders.

Options:
1. Read in place. Keep the import as it is. (chosen)
2. Extend the import to every artifact and drop the in-place read.
3. Remove the import button.

## Answer
Read in place. Keep the import as it is.
