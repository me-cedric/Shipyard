# How do the Legacy permission levels map to the assistant of Shipyard?
Legacy has ask, edit and auto. Shipyard keeps two writing levels, Edit with approval and Auto in worktree, and adds Read only. Legacy ask and edit become Edit with approval. Legacy auto becomes Auto in worktree, which never pre-approves Bash. A project with a read only profile gets Read only and no other level. Read only makes no worktree and gives the read tools only.

Options:
1. Two writing levels and Read only, no bypass. (chosen)
2. Copy the three Legacy levels, with a bypass level.
