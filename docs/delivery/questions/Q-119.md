# How do the permission levels of the earlier tool map to the assistant of Shipyard?
The earlier tool has ask, edit and auto. Shipyard keeps two writing levels, Edit with approval and Auto in worktree, and adds Read only. Ask and edit become Edit with approval. Auto becomes Auto in worktree, which never pre-approves Bash. A project with a read only profile gets Read only and no other level. Read only makes no worktree and gives the read tools only.

Options:
1. Two writing levels and Read only, no bypass. (chosen)
2. Copy the three levels, with a bypass level.
