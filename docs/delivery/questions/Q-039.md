# Which servers can the API try view call?
The try view sends a real request from an OpenAPI contract. A contract lists servers, and some are production. A request that writes data can do harm.

Options:
1. Call any listed server. Ask for one click before a request that is not GET, and name the server. (recommended)
2. Call only servers that the person marks as safe in the project.
3. Call a mock server only.

## Answer
Call any listed server. Ask for one click before a request that is not GET, and name the server.
