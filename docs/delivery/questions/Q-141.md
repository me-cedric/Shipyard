# How does an outside agent change a workflow?
The tool `project_write_file` refuses `.shipyard/`: an agent that runs the gates must not edit them. A workflow sets the budget, the tools and the gates of the runs, so an agent that writes it can raise its own limits.

Options:
1. The agent proposes a text. A person reads the diff in Factory / Workflows and applies or discards it. (recommended, built)
2. The agent writes the file when the group `workflows` is on.
