# Where do the tokens in Design / Screens come from without a Figma connection?
REQ-024 reads the tokens of a linked Figma file and shows them beside the tokens of the design doc. No Figma connection exists. The token view shows the colour tokens of `src/ui/tokens/tokens.css`, by family with a count. It reads and changes no file. A Figma read and a comparison with the design doc wait for a Figma connection.

Options:
1. Show the tokens of `src/ui/tokens` only. Add the Figma column when a Figma connection exists. (recommended)
2. Parse tokens from the design doc text and show them in a second column.
3. Hide the token view until a Figma connection exists.

## Answer
Show the tokens of `src/ui/tokens` only. Add the Figma column when a Figma connection exists.
