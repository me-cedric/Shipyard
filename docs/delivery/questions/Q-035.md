# What happens when a person applies a split again after a change of the spec?
A split creates work items with refs to requirements. The spec can change later, and the person can apply the split again. The tracker may already hold the first items. Q-033 sets the match mark of the apply. Use that mark here.

Options:
1. Match each item by its requirement refs. Create only the missing items and show the changed ones for review. (recommended)
2. Always create new items. The person closes the old ones by hand.
3. Block a second apply. The person edits the items in the tracker.
