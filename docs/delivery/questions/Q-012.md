# Is a ref to a work item that the mirror does not hold broken or unresolved?
The tracker mirror fills by polling. A work item can exist in the tracker before the mirror holds it. Health must not raise false findings.

Options:
1. Unresolved until the next sync completes, then broken. (recommended)
2. Broken at once.
3. Never broken. Always unresolved for tracker entities.
