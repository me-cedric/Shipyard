# Run interactive logins in the integrated terminal or in a dedicated sheet?
`codex login`, `claude auth login` and `opencode auth login` open a browser. Some also print a code or prompt in the terminal (the paste-code fallback of Claude Code, the prompts of OpenCode). The person must see and answer them.

Options:
1. Run the login in the integrated terminal (ADR 0012) and show the state after it ends.
2. Run it in a dedicated sheet that shows the output and one input field.

## Answer

The integrated terminal (owner, 2026-11-05): open a terminal tab with the login command ready, and watch the status command until it reports signed in.
