# Who registers the Azure application, and in which tenant?
The Entra ID device code flow needs a public client application registration. The sign-in needs a client id, a tenant (or `organizations`) and the scope `https://ai.azure.com/.default`. The person also needs the role Cognitive Services OpenAI User. The build needs the owner to register the application or to approve one.

Options:
1. The owner registers one multi-tenant public client and ships its client id in `oauth.env`.
2. Each team registers its own and pastes the client id and the tenant.
3. Leave Azure to a pasted key until a registration exists.

## Answer

Option 3 for now (owner, 2026-11-05): skip the Azure sign-in in this change. REQ-006 is deferred; Azure stays a pasted key until a registration exists. The Azure sign-in moved to the change `add-azure-sign-in` (REQ-001).
