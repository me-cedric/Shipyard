# Where does the catalog come from?
The spec says the catalog comes from the pinned compass version. Compass 1.0.2 holds no catalog folder. The reader needs a layout until compass ships one.

Options:
1. Read `<compass tree>/catalog/<group>/<name>/` with the groups `devcontainers`, `agents` and `devops-security`. The OpenSpec guidance ships built in. (recommended)
2. Add a catalog repository setting. The spec lists this as a non-goal.
3. Ship the whole catalog inside Shipyard.
