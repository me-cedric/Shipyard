# Does a run start from a thread without a ticket?
Factory REQ-009 starts a run only from a claimed ticket. A thread may have no ticket. Send to factory as a run must follow that rule or change it.

Options:
1. Create a work item first, then start the run from its claim. (recommended)
2. Allow a run with no ticket and no tracker write.
3. Offer only the work item and let the pickup rules start the run.

## Answer
Create a work item first, then start the run from its claim.
