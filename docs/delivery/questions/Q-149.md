# How does an unknown person ask to join?
A `viewer` has no `code.write`. A pull request from Shipyard needs a branch and a push. The code host checks the push with the token of the person, so a person without access to the repository cannot push.

Options:
1. Shipyard pushes a branch and opens a pull request that adds the person as `viewer`, with the asked role in its text. This one write needs no right. Without a code host connection or access, Shipyard copies the member entry. (recommended)
2. Copy the member entry only. The person sends it to an admin.

## Answer
Option 1: Shipyard pushes a branch and opens a pull request that adds the person as `viewer`, with the asked role in its text. This one write needs no right. Without a code host connection or access, Shipyard copies the member entry. Recommended default, kept: the owner asked to build the rest with sensible defaults (2026-11-06). The owner can change it.
