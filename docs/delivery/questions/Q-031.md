# What happens to a run when its pull request closes without a merge?
The factory spec lists no state for this case. The ticket is not done and the worktree still holds the change.

Options:
1. The run moves to Blocked. A person chooses to reopen or to cancel. (recommended)
2. The run moves to Cancelled and the worktree is removed.
3. The run goes back to Working and opens a new pull request.
