# How do the repo picker, the Projects page and the conflict hand-off work?
The repo picker lists the first 100 repositories of a forge account and filters them in the page. The Projects page is the Projects tab of Home, with one card for each project grouped by host. The conflict hand-off fills the assistant draft with the conflicted files.

Options:
1. Filter in the page, hand to the assistant. (chosen)
2. Search on the forge, start an agent run.
