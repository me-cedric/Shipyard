# Which languages can a project choose for its docs and its pull requests?
The interface ships in English and French. The agents write in any language. The fixed text of a pull request (opening line and headings) has a translation only in English and French.

Options:
1. English, French, German, Spanish, Italian, Dutch and Portuguese, as two-letter codes. The pull request headings fall back to English for a language with no translation. (recommended, built)
2. English and French only, as the interface.
3. Any language code.
