# Which permission levels can a person pick in agent mode?
The earlier tool has permission levels, and a bypass level that needs a warning. Agent mode runs with the permission level of the person. The set of levels is open.

Options:
1. Two levels: edit with approval, and auto inside the worktree. No bypass. (recommended)
2. Three levels: the two above and bypass behind a warning.
3. No choice. The runner default applies.
