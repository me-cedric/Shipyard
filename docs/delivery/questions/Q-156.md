# What does a local project with no code host do with the bootstrap run?
The workflow `bootstrap` ends with a pull request, like `feature`. A local project has no code host, so the run would block at its last step. Shipyard has no local merge of a run branch.

Options:
1. The creator offers the run only with a code host. A local project starts later or with issues, and `docs/brief.md` and `AGENTS.md` let any AI tool start from the brief. (recommended, built)
2. A second workflow with no pull request, whose branch the person merges by hand.
3. A local merge of the run branch in Code.
