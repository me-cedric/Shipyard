# Which folder does a clone use by default?
A clone needs a target folder. A fixed default can hide repositories in an unexpected place.

Options:
1. No default. The person picks a folder each time. (recommended)
2. A default parent folder in Settings / Me. The person can change it.
3. The home folder of the user.
