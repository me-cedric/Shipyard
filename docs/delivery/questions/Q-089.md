# Where does the file viewer open from in this stage?
REQ-036 lists four sources: the Changes tree, a commit, a pull request file and a ref. The viewer is a dialog. It opens now from a pull request file and from a scanner finding, at the line of the finding. The Changes tree, the commit view and the ref chip are in views that other stages own.

Options:
1. Open from a pull request file and a finding now. Wire the other three when their views change. (recommended)
2. Add the open action to the Changes tree, the commit view and the ref chip in this stage.
