# Does junior mode do more than open Knowledge?
Master plan section 6 names junior mode: an Explain action on every entity, and a Learn path. Shell REQ-009 says that a role changes the home view and the sidebar order only, and that no role loses a view. No spec text says that junior mode hides, adds or changes a control.

Options:
1. Junior mode is the role home only: Knowledge opens first. Explain and Learn stay open to every role. (recommended)
2. Junior mode also pins the Explain action in the inspector of each entity.
3. Junior mode also shows a guided first path in Knowledge / Learn. This needs a change to REQ-016 (no tour).
