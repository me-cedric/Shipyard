# Sign out of what?
The design shows one Sign out. Shipyard has no account of its own, only a sign-in for each connection.

Options:
1. Remove the tokens of the code host and the issue tracker from the keychain, after a confirmation. The AI tools stay signed in.
2. Remove every sign-in, AI tools included.
3. Remove the row.

## Answer
Option 1: after a confirmation, remove the tokens of the code host and of the issue tracker from the keychain on this computer. The AI tools stay signed in. (2026-11-20)
