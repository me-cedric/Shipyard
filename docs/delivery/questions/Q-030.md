# Where does a project declare its gate commands?
The gate before a pull request runs lint, typecheck and tests. No spec names the file that holds those commands.

Options:
1. In .shipyard/project.yaml, as a list of commands. (recommended)
2. In .shipyard/automation.yaml next to the pickup rules.
3. Read them from the project AGENTS.md text.
