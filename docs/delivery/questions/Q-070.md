# Where do the pins of the Home widgets live?
REQ-024 says that the pins are a per-person setting. The preferences file has no field for a list of pins, and W8 stage 2 has no backend change for it.

Options:
1. Keep the pins in the webview storage of this machine. They survive a restart but not a new machine. (recommended for now)
2. Add a `pins` list to the preferences file of the app data folder, with a command to read and write it.
3. Store the pins in the project dashboard file. The whole team then shares them, which REQ-024 does not allow.
