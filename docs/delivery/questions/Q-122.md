# How does Shipyard read the calendar, plan and design files?
`docs/planning/calendar.json` and `plan.json` are read in place when no YAML file exists, and a save writes them back in their own format. A holiday keeps its name, and a task keeps its duration, predecessors and note. The import copies both files as YAML. A decision maps to the first member and a pinned start date; a task that no sheet holds is left out. The files of the designs folder (HTML, images, `.fig`, two levels deep) that no screen names are listed as screens. The `docs/design.md` doc, `docs/workflows` and `docs/architecture` are not read yet.

Options:
1. Read the JSON in place, write it back in its own format, scan the designs folder. (chosen)
2. Convert the JSON to YAML on the first open.

## Answer
Read the JSON in place, write it back in its own format, scan the designs folder.
