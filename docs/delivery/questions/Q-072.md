# How does the webview read the theme logo and the architecture view images?
The deck theme names a logo by repository path, and the architecture dossier takes one PNG for each view. The webview has no command that reads a binary file, and no view renders an architecture image on demand. The slide theme shows no logo and the dossier gets no view image.

Options:
1. Add a command that reads a repository file as base64. Slides show the logo, and Documents sends the PNG of each architecture view that the Design view renders. (recommended)
2. Let the Rust store render the logo and the views itself, with no webview image.
3. Drop the logo and the view images from this version.
