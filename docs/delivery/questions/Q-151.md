# Can a match on the git e-mail give each right?
The git e-mail is not verified: a person can set any e-mail. The account of a connection is verified by its token. A desktop app cannot stop a person who edits files with another tool, so a stricter match adds little. The code host checks each push and merge.

Options:
1. An e-mail match gives the full rights of the member. The guide states the limit. (recommended)
2. An e-mail match gives no `admin` and no `project.settings`. A verified account gives each right.

## Answer
Option 1: An e-mail match gives the full rights of the member. The guide states the limit. Recommended default, kept: the owner asked to build the rest with sensible defaults (2026-11-06). The owner can change it.
