# How do own rules, policy packs and plugin switches work?
A rules file (.md or .txt, 256 KB at most) is copied to .agents/instincts and never replaces a file. Remove deletes an instinct, or switches a skill or a pack off through ac. Three policy packs are built in (solo-dev, safe-local-work, strict-enterprise), and a second apply replaces the first. A plugin switch stops or starts the MCP servers that the plugin added. Remove deletes only the files that still have the recorded hash. Undeploy of a catalog component does the same by comparing the bytes with the catalog.

Options:
1. Built-in packs, hash-checked removal, no file of a person is deleted. (chosen)
2. Read the packs from the compass tree and delete every file of a plugin.
