# Who are the default reviewers of a pull request that a run opens?
The compass pr-flow rule asks for at least one reviewer and says to ask when none is named. A run has no person to ask in the middle of a tick.

Options:
1. A reviewer list in .shipyard/automation.yaml. An empty list gives an Inbox card that asks for a name. (recommended)
2. The other members of the team with the role developer or architect.
3. Always ask in the Inbox.

## Answer
A reviewer list in .shipyard/automation.yaml. An empty list gives an Inbox card that asks for a name.
