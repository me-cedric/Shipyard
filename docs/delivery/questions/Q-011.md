# Does ref detection skip refs inside code spans and code blocks?
Refs appear in documentation as examples inside code. A chip on an example would add noise and false backlinks.

Options:
1. Skip refs in code spans and code blocks. A person can still cite a ref in prose. (recommended)
2. Detect refs everywhere, including code.
3. Skip code blocks only. Detect refs in code spans.

## Answer
Skip refs in code spans and code blocks. A person can still cite a ref in prose.
