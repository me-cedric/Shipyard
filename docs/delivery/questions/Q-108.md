# Which ticket fields can a person edit?
The tracker write trait holds the title, the description, the estimate in days and the parent. A ticket edit sets the title and the description. A label can be added, not removed: the trait has no remove call. Type, priority and due date need new calls in each of the six trackers.

Options:
1. Title, description and label add now. (chosen)
2. Add remove-label, type, priority and due date to the trait and the six adapters.
