# Does the view offer the Codex device code (beta)?
`codex login --device-auth` helps on a remote or locked machine. It is a beta and the person must enable it in the ChatGPT settings. The browser login uses the local callback port 1455, which can be busy.

Options:
1. Offer it only as a fallback after the browser login fails.
2. Do not offer it until it leaves beta.

## Answer

Offer both (owner, 2026-11-05): the browser sign-in by default, and a "Use a code instead" link that runs `codex login --device-auth`.
