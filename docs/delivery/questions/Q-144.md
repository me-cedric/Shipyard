# Does the team file keep the field `trackers` for the accounts?
The owner asked for a field `accounts` with the issue tracker and code host logins. The member already has `trackers`, which holds the same values (a Jira account id, a GitHub login). A new name needs a migration of each team file, and an older Shipyard refuses an unknown field.

Options:
1. Keep `trackers` in the file. The view calls it Accounts. (recommended)
2. Rename it to `accounts`, read both for one version, write `accounts`.

## Answer
Option 1: Keep `trackers` in the file. The view calls it Accounts. Recommended default, kept: the owner asked to build the rest with sensible defaults (2026-11-06). The owner can change it.
