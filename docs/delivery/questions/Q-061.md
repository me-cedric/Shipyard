# Do the budgets per day and per member need a token limit too?
REQ-022 asks for a budget in tokens and money per run, per day and per member. W7 enforces the money budgets per day and per member. A run has a token limit through the engine setting `max_tokens`. The `budgets` block of `.shipyard/automation.yaml` holds USD only.

Options:
1. Keep money only for a day and a member. Tokens show in Factory / Usage but do not pause a run. (recommended)
2. Add a token limit for each day and member budget, with the same alert at 80 % and pause at 100 %.
3. Replace money with tokens for a day and a member.
