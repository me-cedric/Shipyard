# Which format do dates and numbers use with a pack?
With a pack, the interface gets English for each missing text, and the code formats dates, numbers and the assistant prompts with the built-in language, so English. The page language is the pack code.

Options:
1. Keep the English format now. Use the pack code for dates and numbers in a later change. (recommended, built)
2. Use the pack code for dates and numbers now, in each view.
