# How does a deploy reach the remote of a child project?
A deploy writes a branch and a commit in a local clone of the child. The earlier tool pushed straight to the child. Automation writes are off by default, and a push is a write that needs a person.

Options:
1. Stop at the local branch. The person pushes and opens the pull request in Code. (recommended)
2. Push the branch after one click in the deploy view.
3. Push the branch and open a pull request after one click.

## Answer
Stop at the local branch. The person pushes and opens the pull request in Code.
