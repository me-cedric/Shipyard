# Which settings does Settings / Me hold beyond the current six?
REQ-010 lists theme, contrast, density, fonts, reduced motion, language, shortcuts, notifications and the detected agent CLIs. Settings / Me holds theme, language, release address, role, density and contrast. A field for fonts, shortcuts and the notification sources needs a new preference in the Rust store. Reduced motion follows the system setting. The runners group of Settings / Connections lists the detected agent CLIs.

Options:
1. Keep the six settings. Reduced motion follows the system. The detected CLIs stay in Settings / Connections. Add fonts, shortcuts and notification sources only when a person asks. (recommended)
2. Add a preference for each missing item, with a row in Settings / Me.
3. Move the detected CLIs into Settings / Me and keep a link in Settings / Connections.

## Answer
Keep the six settings. Reduced motion follows the system. The detected CLIs stay in Settings / Connections. Add fonts, shortcuts and notification sources only when a person asks.
