# Does the Legacy import read the folders that a Legacy project moved?
Legacy keeps the folder of each artifact kind in its machine registry (`RepoPaths`), not in the repository. The import cannot see a moved folder. It reads the Legacy default paths: `docs/decisions`, `docs/delivery/questions`, `docs/openspec`, `docs/costing`, `docs/planning/team.json`, `docs/personas/personas.json`, `docs/delivery/tickets.config.json`.

Options:
1. Read the default paths only. A person moves the folders first. (recommended)
2. Let the person type the Legacy folder of each kind in the import view.
3. Read the Legacy registry file on this machine.
