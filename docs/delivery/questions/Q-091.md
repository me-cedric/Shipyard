# Does the project import read the folders that a project moved?
The folder of each artifact kind can sit in a machine registry, not in the repository. The import cannot see a moved folder. It reads the default paths: `docs/decisions`, `docs/delivery/questions`, `docs/openspec`, `docs/costing`, `docs/planning/team.json`, `docs/personas/personas.json`, `docs/delivery/tickets.config.json`.

Options:
1. Read the default paths only. A person moves the folders first. (recommended)
2. Let the person type the folder of each kind in the import view.
3. Read a registry file on this machine.
