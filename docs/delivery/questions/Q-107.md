# How does a force push check its lease?
libgit2 has no push lease. The force push reads the heads that the remote lists, compares the head of the working branch with the remote tracking ref of the last fetch, and refuses when they differ. A push of another person between the check and the send is not caught: the window is a few milliseconds.

Options:
1. Compare before the send. (chosen)
2. Run the `git` program with `--force-with-lease`, which checks on the server.
