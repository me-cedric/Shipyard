# Where does a spec define a term?
The glossary comes from the specs. The spec template has no glossary section, so no term is marked. A guess from the text would give wrong terms.

Options:
1. Each spec gets a `### Glossary` list of `term: meaning` lines under `## Purpose`. The schema template adds it. (recommended)
2. A project file `docs/glossary.md`. The Learn view reads it.
3. A term is the bold text on its first use in a spec.
