# Where does a project record the components that it deployed?
REQ-010 says a deploy records the component and its version in the project. The plan names `.shipyard/project.yaml`. That file refuses unknown fields and holds no machine state, so a new field changes the codec, the schema and the generated types.

Options:
1. A separate file `.shipyard/components.json` that maps a component id to its version. (recommended)
2. A `components` field in `.shipyard/project.yaml`, with a schema change.
3. The app data folder. The record would not follow a clone.

## Answer
A separate file `.shipyard/components.json` that maps a component id to its version.
