# Where does the externalBin sidecar of the shipyard CLI live in the Tauri config?
`tauri-build` fails when a file in `externalBin` is missing, also for `cargo test` and `pnpm tauri dev`. The entry is therefore in `crates/shipyard-app/tauri.release.conf.json`, which `pnpm tauri:release` merges. `tauri.conf.json` has no `externalBin`. The signing and the notarisation of the sidecar stay with the owner.

Options:
1. Keep the entry in the release config. A release build runs `pnpm tauri:release`. (recommended)
2. Move the entry to `tauri.conf.json` and build the sidecar before every `cargo` command (a `build.rs` step or a stub file).
