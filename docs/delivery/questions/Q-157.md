# What happens to the existing docs when the docs language changes?
Settings / Project edits the docs language. The existing specs and docs stay in the old language.

Options:
1. Nothing: the next agent brief uses the new language, and a person starts a docs run to translate when they want it. (recommended, built)
2. Shipyard offers a translation run of each doc after the change.
