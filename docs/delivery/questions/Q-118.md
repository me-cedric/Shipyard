# How does Doctor install a missing tool and keep its ledger?
A tool installs only after a click, with a fixed command through the first package manager that exists (brew, winget or npm), never a shell line and never sudo. The ledger keeps one snapshot of the findings each time they change, 100 at most, in the app data folder. It does not yet propagate to linked projects.

Options:
1. Fixed package manager commands, ledger in the app data folder. (chosen)
2. A shell bootstrap and a ledger in the repository.
