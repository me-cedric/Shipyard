# How does Pull requests know that the project has no forge connection?
REQ-025 shows one Connect action in place of the list when the project has no forge connection. `pulls_list` returns the mirror only: an empty mirror and a missing connection look the same. A connected forge with no pull request shows Connect too, and the Open pull request action hides with it.

Options:
1. An empty mirror shows Connect. Open pull request shows when the mirror has a row. (recommended)
2. Add a command that tells whether the project has a forge connection. The view shows Connect only without one, and Open pull request always.
