# Which copy of the team file gives the rights?
A person can change the team file in the working copy and give themselves `admin`. The default branch is reviewed through pull requests. A project with no remote has only the working copy.

Options:
1. The team file of the default branch, as last fetched. With no remote, the working copy. A difference shows a warning. (recommended)
2. The team file of the working copy, with a warning when it differs.

## Answer
Option 1: The team file of the default branch, as last fetched. With no remote, the working copy. A difference shows a warning. Recommended default, kept: the owner asked to build the rest with sensible defaults (2026-11-06). The owner can change it.
