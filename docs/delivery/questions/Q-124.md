# How do the SBOM, the security score, the BDD view and the request tree work?
The SBOM is a CycloneDX 1.5 file that Shipyard builds from `Cargo.lock`, `package-lock.json` and `pnpm-lock.yaml`, with no tool to install (Legacy runs osv-scanner). It goes to `docs/security/sbom.cdx.json` after a click. The security score is 100 minus a penalty for each finding of the last scanner reports: critical 25, high 10, medium 4, low 1. The BDD view lists each scenario of each test plan with the verdict from the `.json` beside the plan; a scenario with no run, or an unknown verdict, is not covered. The request tree reads the usage events of the run log of one run and nests them by step.

Options:
1. Read the lock files and the run log directly. (chosen)
2. Call osv-scanner for the SBOM and read the session transcripts for the tree.
