# How does a request for changes work on GitLab?
REQ-021 asks for approve and request changes. GitLab has no request-changes call in its stable API. Approve works. The adapter now posts the text as a note that starts with `Changes requested:`, so no reviewer state changes and the verdict list shows approvals only. GitLab has no rebase merge in the same call either: Merge offers merge and squash on GitLab.

Options:
1. Post the text as a note and show approvals only. Offer merge and squash on GitLab. (recommended)
2. Use the reviewer state API of GitLab 17 and later, and refuse older servers.
3. Hide Request changes and Rebase on GitLab.
