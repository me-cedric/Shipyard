# Do three new agent actions of the canvas enter the scope?
The background writers of the canvas added three actions that the app does not have today: "Ask an agent to estimate" (Plan), "Fix all with an agent" (health of the project), "Build a tile for me" (dashboards). The first draft of the spec listed them as non-goals.

Options:
1. Out of this change. Each one gets its own change later.
2. In this change, as three more requirements.
3. Only "Ask an agent to estimate" enters this change.

## Answer
Option 2: the three actions enter this change, as the requirements REQ-030, REQ-031 and REQ-032. The owner chose it on 2026-11-16. REQ-033 adds the budget and the stop that the constitution (section 5) asks for each agent run.
