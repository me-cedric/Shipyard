# How does the new interface arrive?
The change ships in seven waves. Between the first and the last wave, some functions live in the new place and some in the old place.

Options:
1. Each wave replaces its pages on main. The old pages of a wave go when its new pages pass the inventory test.
2. A switch "New interface" in Setup / Me. Both interfaces stay until the last wave, then the switch goes.
3. A long branch: nothing reaches main before the last wave.

## Answer
Option 1: each wave replaces its pages on main. The old pages of a wave go when its new pages pass the inventory test. The owner chose it on 2026-11-16.
