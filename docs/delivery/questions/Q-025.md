# How does a run leave Blocked?
A run is Blocked when a connection, a runner or an approval is missing or rejected. The plan does not say how it leaves that state.

Options:
1. On the next tick after the cause is gone, or by a click of the person. (recommended)
2. Only by a click of the person.
3. Only by cancel. A new run replaces it.
