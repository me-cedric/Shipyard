# How does knowledge get the code graph?
The code graph needs an index of the code. The project may already have one from the codebase-memory tool. Shipyard has no parser of its own.

Options:
1. Read the codebase-memory index through its MCP server, listed in Settings / Connections. One Index action builds it. (recommended)
2. Build a file and import graph from the repository with no code symbols.
3. Leave the code graph out of this version.
