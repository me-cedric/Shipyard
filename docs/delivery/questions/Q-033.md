# How does apply match a row to its ticket?
A second apply must not create a duplicate ticket. The tracker has no field for the estimate ref of a row.

Options:
1. Store the est: ref of the row in a ticket label. (recommended)
2. Store the ref in the ticket description.
3. Match by the title of the ticket.

## Answer
Store the est: ref of the row in a ticket label.
