# Which start does the creator choose by default?
The owner offered two starts: a Factory run that bootstraps the project, or starter issues on the issue tracker that the Factory picks up. The run needs a code host, because its last step opens a pull request. The issues need an issue tracker and a write to it.

Options:
1. The run when the project has a code host, else the issues when it has an issue tracker, else later. (recommended, built)
2. Always the issues when there is an issue tracker: each step of the work is a ticket that the team sees.
3. Always later: the person starts the work from Factory or Work.
