# How does an outside agent reach the Shipyard MCP server?
The server listens on 127.0.0.1 with a long-lived token in the app data folder. Each group of tools (read, write, git, forge, exec, delivery) is a switch, off by default, and the tools work on the open project. The .mcp.json entry reads the token from the variable SHIPYARD_MCP_TOKEN, so no secret goes in the repository. There are no ticket, QA or ADR tools yet.

Options:
1. HTTP with a token in a variable, groups off by default. (chosen)
2. Stdio relay with no token.

## Answer
HTTP with a token in a variable, groups off by default.
