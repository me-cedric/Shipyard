# Is the day rate in the team file sealed?
Day rates and margins are sensitive. The estimate sheets can be sealed with a project passphrase. The team file holds the day rate as text.

Options:
1. Seal the day rate field with the project passphrase when the seal is on. (recommended)
2. Keep the day rate as plain text in the team file.
3. Keep day rates in the sealed sheets only, by role.
