# When does the tickets config reach a tracker write?
The tickets setup (issue types, estimate field, hours per day, labels, spec address, hierarchy) is saved in `docs/delivery/tickets.config.json`. The Jira create call still sends `Epic` and `Story`, and the Work apply still counts the hours per day it had. The config is stored, not yet used.

Options:
1. Store the config now, wire it into create and apply in the next change. (chosen)
2. Wire it now: a new argument on `TrackerWrite::create` for six adapters and their tests.
