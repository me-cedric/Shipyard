# Where does the remote watch interval live?
The interval was set for each project, 15 minutes by default. The constitution keeps per-machine preferences out of the repository. A shared value in the project file would force one interval on every member.

Options:
1. A per-machine preference for each project in the app data folder, 15 minutes by default. (recommended)
2. The project file `.shipyard/project.yaml`, shared by the team.
3. A global value for all projects.
