# Which value gives the id of a project ref?
The ref is `project:<id>`. Two clones of one repository share one project file. A rename of the project must not break the refs.

Options:
1. The key in `.shipyard/project.yaml`. The key is short and stable. (recommended)
2. The name. A rename breaks refs.
3. A generated id stored in the file.
