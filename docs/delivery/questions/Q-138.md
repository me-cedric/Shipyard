# Does a person who updates Shipyard see the tour once?
The preferences of an existing install have no `tourSeen` value. The default is false, so the tour opens once after the update.

Options:
1. Show it once after the update: the person learns about the permissions step.
2. Show it only on a fresh install: mark it seen when `prefs.json` already exists.

## Answer

Default until the owner decides: option 1. It is one click to close.
