# Can Upgrade limit the update to a selection of stale entries?
`ac sync` writes the whole project. It has no option to sync one entry. A selection can only choose which absent skills and packs switch on. Every stale entry updates in the same call.

Options:
1. A selection chooses the absent entries to switch on. Stale entries always update together. The view says which entries changed. (recommended)
2. Ask compass for `ac sync --only <kind:id>`, and keep Upgrade for all until it ships.
3. Remove the selection and keep one Upgrade action.

## Answer
A selection chooses the absent entries to switch on. Stale entries always update together. The view says which entries changed.
