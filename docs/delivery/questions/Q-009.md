# Does the app install an update by itself?
The update check finds a new version. Legacy tells the person. An automatic install changes a tool that runs agents.

Options:
1. Tell the person only. The person starts the install. (recommended)
2. Download in the background. The person starts the install.
3. Install at the next restart without a prompt.
