# What does a plugin pack with an unknown key do?
The backend checks the file of a plugin pack, but only the view knows the English keys. A file import refuses an unknown key. A pack in the library can hold a key that an update removed.

Options:
1. Keep the pack, and ignore each unknown key when the view loads it. The file import refuses it. (recommended, built)
2. Check the keys in the plugin review too, and refuse the pack item.
