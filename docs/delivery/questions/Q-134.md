# How does the view show Gemini, `agy` and Copilot state with no status command?
Antigravity CLI and Copilot CLI have no documented status command. Copilot environment tokens also override the stored login. `opencode auth list` prints an unconfirmed format. Shipyard must not read their credential stores (ADR 0017).

Options:
1. Show "Unknown" with "Sign in" and no guess. Parse `opencode auth list` only after a test run confirms its output.
2. Show "Signed in" after a login that ended with exit 0, and keep that mark on this machine until the person signs out.
3. Run a small test prompt through the tool and show the result.

## Answer

Infer from the last run (owner, 2026-11-05): show "Not checked" until a run; a run that fails with a sign-in error shows "Signed out" with a Sign in button.
