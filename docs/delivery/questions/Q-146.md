# Where does the audit log live?
Machine state stays out of the repository (constitution 1.3). A log in the app data folder shows only the writes of this machine. The history of the code host and the issue tracker already shows who pushed, merged or commented.

Options:
1. One JSON line per write in `audit/<project key>.jsonl` in the app data folder, 90 days, plus `by` in each run log event. (recommended)
2. Also post the line of each gated write to the issue tracker ticket.
3. A file in the repository, committed with each write.

## Answer
Option 1: One JSON line per write in `audit/<project key>.jsonl` in the app data folder, 90 days, plus `by` in each run log event. Recommended default, kept: the owner asked to build the rest with sensible defaults (2026-11-06). The owner can change it.
