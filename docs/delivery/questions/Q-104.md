# Where does Shipyard read the Legacy project registry?
Shipyard reads `projects.json` in the Legacy app data folder: id, name, path and paths only. The address, the user and the overrides are never read. The folder is `Library/Application Support/legacy` on macOS, `%APPDATA%/legacy` on Windows and `$XDG_DATA_HOME/legacy` on Linux. A Legacy project that is in the Shipyard list already, or whose folder is gone, does not show. The first run shows the "Legacy" group. The project menu needs the same group: the menu belongs to the shell.

Options:
1. Read the file at each list. (chosen)
2. Import the registry once into the Shipyard registry.
3. Ask the person for the registry path.
