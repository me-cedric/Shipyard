# Does Shipyard read the project list of another app?
No. Shipyard reads no project list of another app. A person opens a folder, and the layout detection gives a folder with no project file its paths (Q-102).

Options:
1. Read no outside project list. (chosen)
2. Import an outside project list once into the Shipyard registry.
3. Ask the person for the path of a project list.
