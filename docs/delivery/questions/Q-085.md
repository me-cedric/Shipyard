# Where does a person set the remote watch interval?
Q-042 puts the interval in a per-machine file for each project, 15 minutes by default. The commands `code_watch_interval` and `code_watch_interval_set` read and write it (1 to 1440 minutes). No view calls them yet.

Options:
1. One number field in Settings / Project, in the personal group. (recommended)
2. One menu in the Code header, next to the branch selector.
3. Keep the commands without a view: the file is the only way to change it.
