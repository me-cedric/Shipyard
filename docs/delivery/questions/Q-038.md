# How does a screen or an ADR start a run?
A factory run starts only from a ticket that sync claimed. A screen or an ADR is not a ticket. The design to code action needs a path to a run.

Options:
1. The action creates a work item that cites the ref, after one click. Normal pickup then starts the run. (recommended)
2. The action starts a run with no ticket. This breaks the factory rule that a run needs a claimed ticket.
3. The action only copies a brief to the clipboard.

## Answer
The action creates a work item that cites the ref, after one click. Normal pickup then starts the run.
