# How does an outside agent ask a person a question?
A run agent asks with `ask_question`: the question shows in the Inbox, and the answer goes back to its run. An agent that a person runs outside Shipyard has no run, so the answer has no place to go.

Options:
1. The tool waits: the question shows in the Inbox, and the tool call returns the answer. It is simple for the agent, but the call can wait a long time, and the agent or its client can stop it first. (recommended, with a limit of 10 minutes and a clear refusal at the limit)
2. The tool returns a question id at once, and the agent reads the answer with a second tool later. A long wait is safe, but the agent must call again, and a person can answer after the agent has stopped.
3. No question tool: the agent asks in its own terminal. Nothing to build, but the question is not in the Inbox and is not kept with the specs. (chosen)

## Answer
No question tool for an outside agent (owner, 2026-11-26). The agent asks in its own chat, or through the ticket with `ticket_comment`. When a person works only in an outside agent, the question is not the responsibility of Shipyard.
