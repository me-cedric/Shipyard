# What does the close guard of Shipyard hold on?
The earlier tool holds the window while files are uncommitted. Shipyard holds it while a factory run or an assistant turn works, and asks Keep working or Close anyway. Uncommitted files do not hold the window: a developer closes with changes all the time. The auto-commit option of a project commits the pending changes on sync and when the window closes. The option lives in the app data folder, not in the repository.

Options:
1. Hold on runs and turns, auto-commit on sync and on close. (chosen)
2. Hold on uncommitted files.
