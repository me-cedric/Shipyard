# What is the equivalent of the Orca integration?
Orca is an outside agent environment with its own `orca` command. Shipyard reads only `orca terminal list --json` and brings a terminal forward with `orca terminal switch`. Shipyard never starts, stops or removes a session. Factory / Sessions shows a list of the Orca sessions and an open on a click. Shipyard does not remove an Orca session, because the session belongs to Orca. The worktree sessions that Shipyard starts for a run are in the Sessions list already, and the kill switch stops them.

Options:
1. Read and open only. (chosen)
2. Also remove an Orca session or its worktree from Shipyard.

## Answer
Read and open only.
