# What is the equivalent of the Legacy Orca integration?
Orca is an outside agent environment with its own `orca` command. Legacy only reads `orca terminal list --json` and brings a terminal forward with `orca terminal switch`. It never starts, stops or removes a session. Shipyard does the same in Factory / Sessions: a list of the Orca sessions and an open on a click. Shipyard does not remove an Orca session, because the session belongs to Orca. The worktree sessions that Shipyard starts for a run are in the Sessions list already, and the kill switch stops them.

Options:
1. Read and open only, as Legacy does. (chosen)
2. Also remove an Orca session or its worktree from Shipyard.
