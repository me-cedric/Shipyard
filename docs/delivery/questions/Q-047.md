# Does an agent-mode thread keep one worktree for all its turns?
Agent mode changes files in a worktree. A thread has many turns. One worktree per thread keeps the changes together. One worktree per turn isolates each turn but spreads the work.

Options:
1. One worktree for each thread. It lives until the person discards or sends it. (recommended)
2. One worktree for each turn.
3. A person picks at the start of the thread.

## Answer
One worktree for each thread. It lives until the person discards or sends it.
