# Is a new remote repository always private?
`create_repo` makes a private repository on GitHub and GitLab, and needs the click of a person. Azure DevOps has no visibility per repository: the project decides. On GitHub, an owner that is not the account uses the organization route. The Azure DevOps push marker uses the security namespace "Git Repositories", bit 4, for one repository. A listing still says nothing.

Options:
1. Always private, no option. (recommended)
2. Add a visibility choice in the create dialog.
