# Who is the admin of a new team file?
`team-rights` (ADR 0019) gives each right to a project with no member, and `viewer` to an unknown person once the team file has a member. The creator writes the person and the members to `.shipyard/team.yaml`. Before `team-rights` lands, the team file has no `admin` and no `emails` field.

Options:
1. When `team-rights` lands, the creator writes `admin: true` and the git e-mail for the person who creates the project. Until then it writes the name, the handle and the role. (recommended)
2. The creator writes no team file when the person is the only member.
