# Does a save from the form keep the layout of the file?
The form writes the file through the shared YAML writer. The comment lines at the top stay. A comment inside the steps and a list on one line (`tools: [a, b]`) do not stay. The text view keeps the file as typed.

Options:
1. Keep the top comment, write the rest in the style of the shared writer. (recommended, built)
2. Patch only the changed lines of the text, to keep each comment.
