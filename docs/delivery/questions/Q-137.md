# Does Shipyard ask for Full Disk Access on macOS?
Shipyard reads and writes the project folders. macOS protects Documents, Desktop, Downloads, the removable volumes and the network volumes. Full Disk Access covers all of them, but an app cannot ask for it: the person must add the app by hand in System Settings, and it gives access to the mail and the messages too.

Options:
1. Ask for Documents, Desktop and Downloads only, after a click. A project on a removable volume gets the macOS prompt when it opens.
2. Also show a Full Disk Access row that opens System Settings.

## Answer

Option 1 (the owner kept the recorded default, 2026-11-06). It asks for the least access.
