# Where do the project overrides of a personal preference live?
A project can override a personal preference, such as the accent colour. The shell has a Non-Goal: no per-project setting for a personal preference. Overrides are kept in the registry, never in the repository.

Options:
1. The registry in the app data folder. The repository stays free of personal values. (recommended)
2. `.shipyard/project.yaml`. The team shares the overrides, but the file then holds personal values.
3. No override. Remove the feature.

## Answer
The registry in the app data folder. The repository stays free of personal values.
