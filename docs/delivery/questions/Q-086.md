# Do the terminal events use tauri-specta typed events?
The events `terminal-output` and `terminal-exit` use a fixed name, like the factory and sync events. The payload type `TerminalOutput` is in the generated bindings, and a comment names the events. A typed `events` object would check the name and the payload in the view, but it needs `mount_events`, and the exit payload becomes an object.

Options:
1. Keep the fixed names and the exported payload type, as the other events do. (recommended)
2. Move the terminal events to tauri-specta typed events, and the other events later.
3. Move all events to typed events in one change.
