# What happens when nobody answers?
A run in WaitingForAnswer spends no budget and has no stall timeout. A question can stay open for weeks and hold a claim and a concurrency slot.

Options:
1. One reminder after 24 h. No timeout. The person can cancel the run. (recommended)
2. Cancel the run after a set number of days.
3. Go on with the recommended option after a set number of days. This breaks constitution 5.3.
