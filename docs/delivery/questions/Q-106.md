# Are the personas, assignments and tickets config read in place?
Shipyard reads `docs/personas/personas.json` and `docs/delivery/assignments.json` where the existing layout keeps them, and reads and writes `docs/delivery/tickets.config.json`. A save merges into the file and keeps the keys that Shipyard does not own. The assignments are read only: the `split-tasks-by-profile` skill edits them.

Options:
1. Read in place, personas and tickets config editable, assignments read only. (chosen)
2. Import them into `.shipyard/` files, as the team was in the first version.
3. Make the assignments editable in Shipyard.

## Answer
Read in place, personas and tickets config editable, assignments read only.
