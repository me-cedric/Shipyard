# What does the file drawer list and change?
The drawer lists the files of the working copy once, as repository-relative paths: the tracked files that exist and the untracked files that the ignore rules keep, 20 000 at most. The search (⌘P) covers the whole list. A file opens in the viewer, shows in Code / Changes or copies its path. The drawer never writes: new, rename and delete of the earlier drawer are not there, so no click guard and no read-only check is needed.

Options:
1. One ignore-aware list, read only. (chosen)
2. One folder level per open, as the earlier drawer, with new, rename and delete behind a click and the read-only lock.

## Answer
One ignore-aware list, read only.
