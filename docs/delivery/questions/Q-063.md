# Does the MCP catalogue list the codebase-memory server?
The code graph calls the codebase-memory server through the Shipyard MCP proxy. The built-in catalogue does not list it, so a person adds it as a custom server. The code looks for an active server whose id holds `codebase-memory`. The tools that it calls (`query_graph`, `index_repository`) are not tested against a live server.

Options:
1. Add a pinned catalogue entry with the id `codebase-memory` and test the two tools against it. (recommended)
2. Keep the custom server only. The Index action shows a hint to add it.
3. Leave the code graph out until a person asks for it.

## Answer
Add a pinned catalogue entry with the id `codebase-memory` and test the two tools against it.
