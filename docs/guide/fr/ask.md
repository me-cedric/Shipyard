# La barre Demander

Demander ou dire à Shipyard, dans la barre du haut, est la seule barre pour une question, un lieu et une action. Appuyez sur Ctrl+K (Cmd+K sur un Mac) pour y aller. Tapez, puis utilisez les flèches et Entrée. Échap la ferme.

## Aller à

Aller à ouvre un lieu, une section, un projet, un élément ou un résultat de recherche.

Tapez quelques mots pour chercher dans le texte de vos documents, décisions, specs, questions, tickets et conceptions. La casse et les accents ne comptent pas (« decision » trouve « décision »), chaque mot doit correspondre, et le dernier mot peut être un début. Les résultats sont groupés par type, montrent un court extrait avec les mots marqués, et placent d'abord une page que beaucoup d'éléments citent. Le document que vous ouvrez depuis un résultat marque les mots.

Choisissez Demander à l'assistant pour mettre ces éléments en contexte dans la zone de message de l'assistant. Rien n'est envoyé avant votre envoi.

## Faire

Faire lance une action ou une requête pour la page que vous voyez. Exemples : Nouvelle fonctionnalité, Ouvrir le mode d'emploi de cette page, Revoir la visite. Une action que votre rôle ne peut pas utiliser ne s'affiche pas.

## Demander

Demandez ce qui bloque, ce qui s'est arrêté ou ce qui vous attend. La réponse nomme chaque fonctionnalité et donne son action : Répondre, Débloquer, Ajouter du budget, Réessayer, Reprendre ou Clore comme terminée.

Tout autre texte va à l'assistant quand vous appuyez sur Entrée.

## L'assistant

L'assistant s'ouvre sur le côté. Posez-lui une question sur le projet. Chaque conversation est un onglet, et un point marque un onglet avec une nouvelle réponse.

- Sous la zone de message, une barre a le bouton de pièce jointe, un bouton avec le modèle et l'effort (il ouvre les modèles de l'outil d'IA, les niveaux d'effort et les modèles des autres outils d'IA), la permission, l'anneau de contexte et Envoyer.
- En mode Agent, la permission est Édition avec accord, Auto (accepte les modifications) ou Ignorer les permissions. Ignorer les permissions saute chaque approbation de Claude Code ou de Codex : Shipyard vous demande la première fois dans chaque projet, le montre en rouge tant qu'il est actif, et le refuse dans un projet en lecture seule et quand l'interrupteur des agents est désactivé.
- Tapez `/` au début d'un message pour lister les commandes de l'outil d'IA sélectionné. Le texte part vers l'outil d'IA tel que vous l'avez tapé.
- Chaque conversation garde une session d'agent, donc un message suivant continue le travail précédent.
- Annuler abandonne les changements que l'assistant a faits dans les fichiers. Sans Annuler, les changements restent.
- Sélectionnez un texte dans une page pour l'envoyer à l'assistant, ou vers Flux comme nouvel élément de travail.
