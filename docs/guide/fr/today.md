# Aujourd'hui

Aujourd'hui vous dit quoi faire maintenant. Le sélecteur en haut a trois sections : Aujourd'hui, Nouvelles et Activité. Un point sur Aujourd'hui dans le menu marque les nouvelles non lues, et une marque montre qu'une exécution ou une session travaille.

## Ce qui vous attend

Le titre donne le nombre de choses qui vous attendent. Une carte montre la première : qui demande, pour quelle fonctionnalité, et la réponse.

- Répondre à une question : appuyez sur un chiffre, puis Entrée, ou tapez votre propre réponse.
- Approuver ou rejeter un changement. Lire un plan, puis l'approuver ou le rejeter avec une note.
- Ouvrir la pull request d'une revue. Un brouillon de revue d'agent qui attend a un lien vers sa pull request.
- Marquer un message comme lu.
- Un changement que les interrupteurs d'automatisation ne permettent pas attend ici votre clic. Les écritures d'une exécution sont une seule question qui nomme chaque effet, avec Étape par étape, Pas encore et Ne plus demander pour cette recette. Voir la page Flux, Approbations.
- Un agent arrêté montre une action principale : Répondre, Débloquer, Ajouter du budget, Réessayer, Reprendre ou Clore comme terminée.

Plus tard déplace la carte à la fin. La liste sous la carte contient les choses suivantes : cliquez sur l'une d'elles pour y répondre d'abord.

La carte montre ce sur quoi vous pouvez agir : les approbations que vos droits permettent, les questions de vos tickets ou de votre rôle, et les revues. Tout le monde montre les choses de toute l'équipe, avec les commandes que vous ne pouvez pas utiliser désactivées. Avec Tout le monde, le nombre du titre peut différer du nombre du menu.

Quand il n'y a rien à montrer, une action ouvre Flux / Liste.

## Le reste de la page

- En cours liste les exécutions qui travaillent sur vos tickets ou qui vous attendent, avec Arrêter, et les dépenses du jour.
- Tant qu'un élément reste à faire, une liste Pour commencer s'affiche (voir Démarrer, Premier lancement).
- Un jour de travail sans temps saisi, une carte vous rappelle de saisir votre temps. Elle n'est pas dans le nombre.
- Les panneaux de votre rôle montrent ce que votre rôle surveille, chacun avec Ouvrir. Choisissez un rôle pour voir les panneaux d'un autre rôle. Un panneau d'un lieu que vous ne voyez pas reste masqué.
- Mon travail contient les tickets que l'outil de suivi vous attribue, groupés en En cours, À faire et Terminé dans les 7 derniers jours. Chaque ligne a son statut et Lancer une exécution.
- Depuis votre dernière visite liste ce qui s'est passé sur vos tickets et vos exécutions depuis la dernière ouverture d'Aujourd'hui, le plus récent d'abord.

Le panneau de la barre de menus montre les mêmes choses qui vous attendent.

## Nouvelles

Nouvelles contient les notifications. Le titre donne leur nombre. Chaque ligne a son action et une commande pour la retirer. Tout marquer comme lu et Effacer agissent sur la liste. Aucune autre page ne contient une liste de notifications. Cliquez sur une entrée pour ouvrir son exécution, sa pull request, sa page Santé ou son brouillon.

Configuration / Moi a un interrupteur pour chaque source de notifications.

## Activité

Activité liste les exécutions en cours et les sessions ouvertes, chacune avec Arrêter.
