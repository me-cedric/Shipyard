# Knowledge

Knowledge turns the project files into pages, documents and slides.

| Tab | Content |
|---|---|
| Graph | The reference graph. Filter by kind. A table view lists the same nodes. |
| Handbook | The pages of the handbook, with their refs as chips. |
| Documents | Export to `.docx` and `.xlsx`. |
| Slides | Decks written as text, with a present mode. |
| Learn | The learning path and the glossary. |
| Dashboards | Dashboards of tiles, saved as files. |

## Graph

An entity that nothing cites shows as an orphan. An entity whose source changed later shows as stale. Select a node to open its entity in the inspector. The code graph needs the codebase-memory index. The view has one Index action when no index exists.

## Edit and export

- Handbook: edit a page and save it to the repository. The app warns when the file changed on disk.
- Documents: export the architecture dossier and the functional documentation as `.docx`. Export a client deliverable as `.xlsx`. An unreadable source gives a named gap. A sealed sheet gives no day rate.

## Slides

A deck uses the project theme. Present mode opens over the window. Press Escape to leave. Reduced motion removes the transitions. A deck does not export as one file yet.

## Dashboards

Move a tile and save. Show as table gives the numbers behind a chart. Pin a tile to show it in Home / My work.
