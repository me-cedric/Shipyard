# Changelog

## [0.1.0]
- Docs chain warnings can be acknowledged with a reason that the team shares in the repository, and each page with stale artifacts shows a red badge; Code / Quality runs the scripts and tests of the project after a click, shows its coverage and verifies all docs; Specs / Test plans generates one scenario stub for each requirement and lists each requirement with its coverage; the work apply lets you approve, edit or drop each row; questions can be deleted after a confirmation, renamed, given a text and an owner from the team; documents can be searched by content, renamed, deleted to the trash and a .docx opens as read-only text.
- The assistant has a Stop button (Escape too) that ends a turn and keeps the reply so far; Markdown shows tables, links that open in the browser and mermaid diagrams in the handbook, documents, ADRs and replies; a GitHub or GitLab connection signs in with the browser; Code / Branches publishes a local project to a forge in one click and shows or changes the origin; a pull request can be closed, sent back to the agent, or archive its spec change; a file opens in your code editor (VS Code, Cursor, Zed, JetBrains, Sublime Text); one broken glab host no longer hides the other accounts.
- The assistant has an Ask menu on each page with canned prompts per item type (decision, spec, work item, run, pull request, file, diagram) in the language of your choice, and Shift+F10 on a focused item opens it; the update check repeats every 6 hours with an auto-check switch; the project profiles set each page to hidden, read-only or editable and assign a profile by e-mail; Design / Diagrams creates draw.io and BPMN boards, converts a board between formats and starts on your default format; the Code conflict dialog counts the chosen blocks, opens the file in your editor and edits the result by hand; Design / Flows adds a Bricks tab and name, subnet and brick columns.
- Knowledge / Learn adds learning paths (courses, certifications and readings, with experts from the team and a tick per person, plus a team progress table) and news feeds that the app reads as plain text and keeps for an hour; Knowledge / Manual ships the user guide inside the app with a full-text search, and the palette action Open the manual for this page opens the section of the current tab; Settings / Agents and rules adds Install the contract, objectives that switch on a set of skills, and the external skills with their drift, a refresh and a reinstall; an applied plugin has a typed settings form and deploys to the child projects; MCP servers show by category, add the recommended set in one click, and Test or Test all says if each server works and how many tools it gives.

## [0.0.1]

### Added

- Project plan, constitution and first architecture decisions.
- Sealing the sheets and day rates now asks for the passphrase twice and seals nothing when the two differ. Send in Work / Time is disabled while an entry goes to the tracker, and the same entry never goes twice, even from two clicks. Today, the start of the plan and the default day of a time entry now follow your time zone and not UTC.
- Each project now keeps its own sync cursor and claims for its tracker container, so two projects on one connection no longer mix. Only the open project polls, a cut-off poll no longer skips unread tickets, and an import never overwrites a newer ticket. A claim stamp counts only from your own account and ages by the clock of the tracker. The browser preview opens a demo project with a tracker, so every space is reachable.
