## Decisions

- Default paths for the new artifact kinds are in `MORE_PATHS` in `shipyard-core/src/project.rs`. A new project file does not write them. They follow the existing layout: `docs/diagrams`, `docs/models`, `docs/api`, `docs/data-models`, `docs/flows`, `docs/designs` (`screens.json`, `design.md`), `docs/delivery/test-plans` (Q-037 option 1).
- `shipyard-store/src/safe_write.rs` is the one write path for W5 files: temp file and rename, and a stamp (modified time and size) check before replace.
- The ref index (`repo_scan.rs`) gets the design and test plan kinds in Phase B, after the rebase. W4 changes the same file.
- The split model produces rows in the shape of the W4 `shipyard_core::work::Row` (`est:<change>#<row-id>`). Phase B maps them and calls the W4 `shipyard_trackers::work::apply`.
