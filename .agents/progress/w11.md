# W11 progress: easy for everyone

Goal (owner, 2026-10-30): anyone on a project can use Shipyard, also with little technical knowledge. Fixes respect the constitution (no taglines, helper text or secondary labels): layout, label wording, defaults, detection, guided flows, one primary action, plain errors with one action.

## Ease-of-use audit (2026-10-30), ranked

1. A spec needs a code-form id: accept a plain title, derive the id.
2. A run starts from a typed ticket key: pick a ticket by title; Start run on the ticket; Sync on the error.
3. Errors show raw, English only, some ask to edit a file: an error contract (code, details, one action), translated, linked to the right setting.
4. Tracker setup spans two pages; scope is free text: auto-link the only tracker; pick the scope from the tracker's projects.
5. Connection form: "Secret" label, empty name, no forge address from the remote, untested after save: "API token" per product, a create-token link, prefill, test on save.
6. A missing agent CLI has no install action in Settings; Node is not installed for npm runners.
7. Get started lacks agent CLI, first decision and assign steps; links open a page, not the form.
8. Decision records and specs open as raw markdown: a form view by default, raw text as an option.
9. A spec has no clear next step; two ways create work items: one primary next action; one way.
10. Long run ids and refs lead cards: lead with the title, keep the ref behind copy.
11. Approvals show raw git: plain words, danger colour, command hidden.
12. Merge ignores failing checks and requested changes: a danger confirm; hide a single merge method choice.
13. Activity shows codes: one translated sentence per event.
14. Juniors land on a black graph: first tab by role (junior Learn, PM Board); titles in the graph.
15. First-run role picker shows only "None": role as named cards, first step.
16. Create project asks for a "Key", no default folder, a plain folder fails with no way out: key from the name, default folder, "Make it a project" on the error.
17. Tab names clash (Specs/Code Changes, Inbox questions/Specs Questions, Work Team/Settings Team).
18. Team cards show bare numbers: a table with headers and units.
19. "Mark for agent" dead end without a pickup label: default pickup label, reason links to the setting.
20. Settings too dense: detect paths, pickers, an Advanced section, runners first.
21. "Kill switch off" reads as an alarm: an "Agents on / stopped" toggle.

Bigger ideas: a setup wizard that detects everything after the role step; one "next step" button per item along the loop; one error rule with a test that blocks raw strings; role sets the order of tabs too.
