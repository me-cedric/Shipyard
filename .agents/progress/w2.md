## Decisions

- Package manager: pnpm 11. Node 26 locally, Node 24 in CI.
- Lint: Biome for TypeScript, `cargo clippy` and `cargo fmt` for Rust.
- Tauri app config lives in `crates/shipyard-app/` (`tauri.conf.json`, `capabilities/`, `icons/`). Identifier `dev.shipyard.app`. Dev port 1420.
- IPC: `tauri-specta` 2.0.0-rc (pinned with `=`). A test in `shipyard-app` writes `src/lib/ipc/bindings.ts`. `pnpm ipc:gen` runs `cargo test --workspace` unfiltered. `pnpm ipc:check` fails when the file changes.
- Mock IPC: `@tauri-apps/api/mocks` `mockIPC` with one handler per generated command. The handler map is typed from `bindings.ts`, so `pnpm typecheck` fails when a command has no mock.
- i18n: a typed catalogue in `src/lib/i18n/` with no dependency. `fr` has the type of `en`, so a missing key fails the typecheck.
- Preferences (theme, language, role, density, contrast) live in `localStorage` for W2. W3 moves them to the app data folder.
- Fonts: Inter from `@fontsource-variable/inter` (bundled by Vite), Departure Mono woff2 in the repo with its OFL licence. Switzer not used (Q-001).
